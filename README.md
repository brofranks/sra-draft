# Symbolic Relation Algebra (SRA)

A Rust library for hybrid symbolic and concrete binary relations. Fields may
range over large symbolic domains stored as binary decision diagrams.
Nonrecursive query combinators fuse by continuation passing and materialize only
at explicit collection points.
